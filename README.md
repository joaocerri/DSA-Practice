# DSA Practice

Repositório dedicado ao estudo e à prática de **Estruturas de Dados e Algoritmos** utilizando a linguagem **C**.



## 📚 Conteúdos

### 01 — Ponteiros

* Ponteiros e endereços de memória
* Manipulação de dados por referência
* Structs e ponteiros
* Alocação dinâmica de memória

### 02 — Listas Encadeadas

* Nós e ponteiros
* Inserção e remoção de elementos
* Busca em listas
* Listas encadeadas simples
* Gerenciamento dinâmico de memória

### 03 — Recursão

* Funções recursivas
* Fibonacci
* Máximo Divisor Comum (MDC)
* Busca do menor elemento
* Soma de intervalos

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/joaocerri/DSA-Practice.git
cd DSA-Practice
```

Compile o arquivo desejado com o GCC:

```bash
gcc arquivo.c -o programa
```

Execute:

**Windows:**

```bash
.\programa.exe
```

**Linux / macOS:**

```bash
./programa
```

Cada exercício pode ser compilado e executado de forma independente.
